# src/lib

Serverlogik und geteilte Helfer, nach Fachbereich sortiert.

Direkt hier liegen nur die Dateien, die fast überall gebraucht werden:
`prisma`, `auth`, `permissions`, `api-response`, `utils`, `site`.

| Ordner | Inhalt |
| --- | --- |
| `agents/` | Agents, Dienstnummern, Ausbildungen, Abwesenheit, Rangänderungen, Auszeichnungen |
| `units/` | Units, Unit-Leitung, Ermittlungsgruppen, Modulrechte |
| `codenames/` | Decknamen und das Discord-Board |
| `duty/` | Dienstzeiten, Spielzeit, Wochenbericht |
| `sanctions/` | Sanktionskatalog, Befugnisse, Wiederholungsprüfung |
| `discord/` | Bot, Nachrichten-Bausteine, Rollen-Sync, Webhooks |
| `contracts/` | Arbeitsverträge, Unterschriften, Vereinbarungen |
| `hr/` | Bewerbungen, Formulartests, Probezeiten, Versetzungen |
| `investigations/` | Ermittlungsakten, Familienakten, Beweiskette, Freigaben, Karte |
| `media/` | Uploads, Bodycam-Clips, Komprimierung |
| `lspd/` | LSPD-Anbindung, Qualitäts- und Korruptionskontrollen |
| `publications/` | Ordnungen, Pressemitteilungen, Veröffentlichungen, Klagen |
| `storage-logs/` | Lagerlogs und Warnungen |
| `audit/` | Audit-Log und Änderungsverlauf |
| `core/` | Einstellungen, Setup, Suche, Benachrichtigungen, API-Tokens, Backups |
| `validations/` | Gemeinsame Zod-Schemas |
